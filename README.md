\## 3. Требования к выполнению



\### 3.1. Тема и концепция



\#### \*\*Название приложения\*\*

HADUKEN — интернет-магазин уличной одежды



\#### \*\*Краткое описание\*\*

HADUKEN — это современный интернет-магазин, специализирующийся на продаже качественной уличной одежды и аксессуаров. Платформа предоставляет пользователям удобный каталог с фильтрацией по размеру, цене и категориям, личный кабинет для управления заказами и избранными товарами, а также возможность отслеживать статус доставки. Административная панель позволяет управлять ассортиментом, обрабатывать заказы и публиковать акции.



\#### \*\*Целевая аудитория\*\*

\- Молодежь (18-35 лет), интересующаяся уличной модой и современным стилем

\- Покупатели, ценящие качественный трикотаж и оригинальный дизайн

\- Коллекционеры, следящие за новыми коллекциями и лимитированными релизами

\- Люди, предпочитающие удобный онлайн-шопинг с доставкой



\#### \*\*Ключевой функционал\*\*

1\. \*\*Главная страница\*\* — витрина с актуальными акциями, новыми коллекциями и популярными товарами

2\. \*\*Каталог товаров\*\* — динамический список одежды с фильтрацией по категориям, размерам, цене

3\. \*\*Детальная страница товара\*\* — подробное описание, фото, выбор размера, добавление в корзину/избранное

4\. \*\*Аутентификация\*\* — регистрация, вход, восстановление пароля

5\. \*\*Личный кабинет\*\* — управление профилем, история заказов, избранное

6\. \*\*Корзина и оформление заказа\*\* — добавление товаров, изменение количества, оформление заказа

7\. \*\*Поиск\*\* — поиск товаров по названию, категории, артикулу

8\. \*\*Административная панель\*\* — управление товарами, заказами, пользователями

\### 3.2. Структура приложения (8+ разделов)



| Раздел | URL | Тип доступа | Описание |

|--------|-----|-------------|----------|

| Главная | `/` | Публичный | Витрина с акциями, популярными товарами, новыми поступлениями |

| Аутентификация | `/auth/\*` | Публичный | Вход, регистрация, восстановление пароля (считается за 1 раздел) |

| Каталог | `/catalog` | Публичный | Список всех товаров с фильтрацией и сортировкой |

| Детальная страница | `/catalog/<id>` | Публичный | Подробная информация о товаре, выбор размера |

| Личный кабинет | `/profile` | Приватный | Информация профиля, настройки |

| История заказов | `/profile/orders` | Приватный | Список всех заказов пользователя, статусы |

| Избранное | `/profile/favorites` | Приватный | Сохраненные товары для быстрого доступа |

| Корзина | `/cart` | Приватный | Товары, ожидающие оформления |

| Поиск | `/search` | Публичный | Поиск товаров с динамическими результатами |

| Админ-панель | `/admin` | Приватный (админ) | Управление товарами, заказами, пользователями |



\*\*Всего разделов: 10 (с учетом /auth как одного раздела)\*\*

\### 3.3. Технологический стек



\#### \*\*Frontend\*\*

| Технология | Обоснование выбора |

|------------|-------------------|

| \*\*HTML\*\* | Семантическая разметка, SEO-оптимизация, поддержка современных веб-стандартов |

| \*\*CSS\*\* | Кастомная стилизация без зависимостей от тяжелых фреймворков, полный контроль над дизайном. 

| \*\*python\*\* | Без использования тяжелых фреймворков для оптимальной производительности. Динамическая загрузка контента, валидация форм, взаимодействие с API |



\*\*Обоснование:\*\* Выбор чистого HTML/CSS обусловлен необходимостью легковесного решения с быстрой загрузкой страниц. Отсутствие фреймворков упрощает отладку и снижает порог входа для поддержки проекта.



\#### \*\*Backend\*\*

| Технология | Обоснование выбора |

|------------|-------------------|

| \*\*Python\*\* | Простота синтаксиса, богатая экосистема библиотек, высокая скорость разработки |

| \*\*MySQL\*\* | Надежная реляционная СУБД, отлично подходит для интернет-магазинов со сложными связями (товары-заказы-пользователи) |



\*\*Обоснование:\*\* Python обеспечивают быструю разработку API. MySQL гарантирует целостность данных, поддержку транзакций и высокую производительность при работе с большими объемами данных.





\### 3.4. Визуальное проектирование интерфейса



\*\*Вариант В: Подробное текстовое описание с разметкой\*\*



\---



\#### \*\*Страница 1: Главная (`/`)\*\*

\- \*\*Тип доступа:\*\* публичный

\- \*\*Основные блоки:\*\*

&#x20; 1. \*\*Шапка (Header)\*\*: логотип "HADUKEN", навигационное меню (Главная, Каталог, О нас), иконка поиска, иконка корзины, кнопка "Войти"/аватар пользователя

&#x20; 2. \*\*Hero-блок\*\*: заголовок "Уличная одежда HADUKEN", подзаголовок "Стиль, который говорит сам за себя", кнопка "Смотреть новую коллекцию" (ссылка на каталог)

&#x20; 3. \*\*Секция "Акции"\*\*: баннеры с текущими скидками (данные из `GET /api/promotions?active=true`)

&#x20; 4. \*\*Секция "Новые поступления"\*\*: горизонтальный скролл из 6 карточек товаров (данные из `GET /api/items?new=true\&limit=6`)

&#x20; 5. \*\*Секция "Популярные товары"\*\*: сетка 4x2 из 8 карточек товаров (данные из `GET /api/items?popular=true\&limit=8`)

&#x20; 6. \*\*Секция "Отзывы"\*\*: слайдер с отзывами покупателей (данные из `GET /api/reviews`)

&#x20; 7. \*\*Футер (Footer)\*\*: контакты, ссылки на соцсети, информация о доставке и возврате



\---



\#### \*\*Страница 2: Аутентификация (`/auth`)\*\*

\- \*\*Тип доступа:\*\* публичный

\- \*\*Состояния:\*\*

&#x20; - \*\*Вход\*\*: форма (email/логин, пароль), кнопка "Войти", ссылка "Забыли пароль?", ссылка "Создать аккаунт"

&#x20; - \*\*Регистрация\*\*: форма (имя, email, пароль, подтверждение пароля), кнопка "Зарегистрироваться"

&#x20; - \*\*Восстановление пароля\*\*: форма (email), кнопка "Отправить ссылку для восстановления"

\- \*\*Динамический контент:\*\* обработка отправки формы с валидацией на клиенте и отправкой на `POST /api/auth/login`, `POST /api/auth/register`, `POST /api/auth/forgot-password`



\---



\#### \*\*Страница 3: Каталог (`/catalog`)\*\*

\- \*\*Тип доступа:\*\* публичный

\- \*\*Основные блоки:\*\*

&#x20; 1. \*\*Шапка и футер\*\* (общие для всех страниц)

&#x20; 2. \*\*Боковая панель фильтров\*\*:

&#x20;    - Категории: Футболки, Худи/Свитшоты, Штаны, Аксессуары

&#x20;    - Размеры: XS, S, M, L, XL, XXL

&#x20;    - Цена: ползунок от минимальной до максимальной цены

&#x20; 3. \*\*Сортировка\*\*: выпадающий список (по новизне, по цене ↑, по цене ↓, по популярности)

&#x20; 4. \*\*Сетка товаров\*\*: карточки товаров (изображение, название, цена, рейтинг)

&#x20; 5. \*\*Пагинация\*\*: кнопки "Загрузить еще" или постраничная навигация

\- \*\*Динамический контент:\*\* товары загружаются с `GET /api/items?category=\&size=\&min\_price=\&max\_price=\&sort=\&page=\&limit=12`

\- \*\*Состояние загрузки:\*\* скелетоны-карточки

\- \*\*Состояние ошибки:\*\* сообщение "Не удалось загрузить товары. Попробуйте позже."



\---



\#### \*\*Страница 4: Детальная страница товара (`/catalog/<id>`)\*\*

\- \*\*Тип доступа:\*\* публичный

\- \*\*Основные блоки:\*\*

&#x20; 1. \*\*Хлебные крошки\*\*: Главная / Каталог / Категория / Название товара

&#x20; 2. \*\*Галерея изображений\*\*: главное фото + миниатюры

&#x20; 3. \*\*Блок информации\*\*:

&#x20;    - Название товара

&#x20;    - Цена (с возможной скидкой)

&#x20;    - Рейтинг и количество отзывов

&#x20;    - Выбор размера (кнопки XS-XXL, отображать наличие)

&#x20;    - Количество товара (счетчик)

&#x20;    - Кнопки: "В корзину", "В избранное"

&#x20; 4. \*\*Табы\*\*:

&#x20;    - Описание: состав, характеристики

&#x20;    - Таблица размеров (сравнение размеров)

&#x20;    - Доставка и возврат

&#x20;    - Отзывы: список отзывов с возможностью оставить отзыв для авторизованных

\- \*\*Динамический контент:\*\* данные из `GET /api/items/<id>`, отзывы из `GET /api/items/<id>/reviews`



\---



\#### \*\*Страница 5: Личный кабинет (`/profile`)\*\*

\- \*\*Тип доступа:\*\* приватный (требуется авторизация)

\- \*\*Основные блоки:\*\*

&#x20; 1. \*\*Боковое меню\*\*: Личные данные, Мои заказы, Избранное, Выход

&#x20; 2. \*\*Блок личных данных\*\*:

&#x20;    - Аватар (иконка пользователя)

&#x20;    - Форма: Имя, Email, Телефон, Адрес доставки

&#x20;    - Кнопка "Сохранить изменения"

\- \*\*Динамический контент:\*\* данные загружаются с `GET /api/user/profile`, сохраняются через `PUT /api/user/profile`



\---



\#### \*\*Страница 6: История заказов (`/profile/orders`)\*\*

\- \*\*Тип доступа:\*\* приватный

\- \*\*Основные блоки:\*\*

&#x20; 1. \*\*Список заказов\*\* (аккордеон или карточки):

&#x20;    - Номер заказа

&#x20;    - Дата

&#x20;    - Сумма

&#x20;    - Статус (Ожидает оплаты, В обработке, В пути, Доставлен)

&#x20;    - Кнопка "Подробнее" для раскрытия деталей

&#x20; 2. \*\*Детали заказа\*\*:

&#x20;    - Список товаров с количеством и ценой

&#x20;    - Итоговая сумма

&#x20;    - Адрес доставки

\- \*\*Динамический контент:\*\* `GET /api/user/orders`



\---



\#### \*\*Страница 7: Избранное (`/profile/favorites`)\*\*

\- \*\*Тип доступа:\*\* приватный

\- \*\*Основные блоки:\*\*

&#x20; 1. \*\*Сетка товаров\*\* (аналогично каталогу) с возможностью удаления из избранного

&#x20; 2. \*\*Кнопка "Добавить все в корзину"\*\*

&#x20; 3. \*\*Пустое состояние\*\*: сообщение "В избранном пока ничего нет" и ссылка на каталог

\- \*\*Динамический контент:\*\* `GET /api/user/favorites`, `DELETE /api/user/favorites/<item\_id>`



\---



\#### \*\*Страница 8: Корзина (`/cart`)\*\*

\- \*\*Тип доступа:\*\* приватный

\- \*\*Основные блоки:\*\*

&#x20; 1. \*\*Таблица товаров\*\*:

&#x20;    - Изображение, название, размер, цена, количество (счетчик), итого за позицию

&#x20;    - Кнопка удаления

&#x20; 2. \*\*Блок итогов\*\*:

&#x20;    - Промокод (поле ввода и кнопка "Применить")

&#x20;    - Сумма за товары

&#x20;    - Доставка (бесплатно от 5000 руб.)

&#x20;    - Итоговая сумма

&#x20;    - Кнопка "Оформить заказ"

&#x20; 3. \*\*Пустое состояние\*\*: сообщение "Корзина пуста" и ссылка на каталог

\- \*\*Динамический контент:\*\* `GET /api/cart`, `POST /api/cart`, `PUT /api/cart/<id>`, `DELETE /api/cart/<id>`



\---



\#### \*\*Страница 9: Поиск (`/search?q=`)\*\*

\- \*\*Тип доступа:\*\* публичный

\- \*\*Основные блоки:\*\*

&#x20; 1. \*\*Строка поиска\*\* с сохраненным запросом

&#x20; 2. \*\*Результаты поиска\*\*: сетка карточек товаров

&#x20; 3. \*\*Состояния\*\*:

&#x20;    - Поиск: спиннер

&#x20;    - Результаты найдены: отображение карточек

&#x20;    - Результатов нет: сообщение "По запросу '\[запрос]' ничего не найдено"

\- \*\*Динамический контент:\*\* `GET /api/search?q={query}`



\---



\#### \*\*Страница 10: Админ-панель (`/admin`)\*\*

\- \*\*Тип доступа:\*\* приватный (только администраторы)

\- \*\*Основные блоки:\*\*

&#x20; 1. \*\*Дашборд\*\*: статистика (количество заказов, выручка, количество пользователей)

&#x20; 2. \*\*Управление товарами\*\*: таблица товаров с возможностью добавления/редактирования/удаления

&#x20; 3. \*\*Управление заказами\*\*: список всех заказов с возможностью изменения статуса

&#x20; 4. \*\*Управление пользователями\*\*: список пользователей, возможность блокировки/выдачи прав админа

\- \*\*Динамический контент:\*\* `GET /api/admin/\*`, `POST /api/admin/\*`, `PUT /api/admin/\*`, `DELETE /api/admin/\*`
