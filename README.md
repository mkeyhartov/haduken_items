# haduken\_items





HADUKEN — интернет-магазин уличной одежды



Краткое описание

HADUKEN — это современный интернет-магазин, специализирующийся на продаже качественной уличной одежды и аксессуаров. Платформа предоставляет пользователям удобный каталог с фильтрацией по размеру, цене и категориям, личный кабинет для управления заказами и избранными товарами, а также возможность отслеживать статус доставки. Административная панель позволяет управлять ассортиментом, обрабатывать заказы и публиковать акции.



Целевая аудитория

Молодежь (18-35 лет), интересующаяся уличной модой и современным стилем

Покупатели, ценящие качественный трикотаж и оригинальный дизайн

Коллекционеры, следящие за новыми коллекциями и лимитированными релизами

Люди, предпочитающие удобный онлайн-шопинг с доставкой



Ключевой функционал

Главная страница — витрина с актуальными акциями, новыми коллекциями и популярными товарами

Каталог товаров — динамический список одежды с фильтрацией по категориям, размерам, цене

Детальная страница товара — подробное описание, фото, выбор размера, добавление в корзину/избранное

Аутентификация — регистрация, вход, восстановление пароля

Личный кабинет — управление профилем, история заказов, избранное

Корзина и оформление заказа — добавление товаров, изменение количества, оформление заказа

Поиск — поиск товаров по названию, категории, артикулу

Административная панель — управление товарами, заказами, пользователями



3.2. Структура приложения (8+ разделов)

Раздел	URL	Тип доступа	Описание

Главная	/	Публичный	Витрина с акциями, популярными товарами, новыми поступлениями

Аутентификация	/auth/\*	Публичный	Вход, регистрация, восстановление пароля (считается за 1 раздел)

Каталог	/catalog	Публичный	Список всех товаров с фильтрацией и сортировкой

Детальная страница	/catalog/<id>	Публичный	Подробная информация о товаре, выбор размера

Личный кабинет	/profile	Приватный	Информация профиля, настройки

История заказов	/profile/orders	Приватный	Список всех заказов пользователя, статусы

Избранное	/profile/favorites	Приватный	Сохраненные товары для быстрого доступа

Корзина	/cart	Приватный	Товары, ожидающие оформления

Поиск	/search	Публичный	Поиск товаров с динамическими результатами

Админ-панель	/admin	Приватный (админ)	Управление товарами, заказами, пользователями

Всего разделов: 10 (с учетом /auth как одного раздела)



3.3. Технологический стек

Frontend

Технология	Обоснование выбора

HTML	Семантическая разметка, SEO-оптимизация, поддержка современных веб-стандартов

CSS	Кастомная стилизация без зависимостей от тяжелых фреймворков, полный контроль над дизайном.

Обоснование: Выбор чистого HTML/CSS/JS обусловлен необходимостью легковесного решения с быстрой загрузкой страниц. Отсутствие фреймворков упрощает отладку и снижает порог входа для поддержки проекта.



Backend

Технология	Обоснование выбора

Python	Простота синтаксиса, богатая экосистема библиотек, высокая скорость разработки

Flask	Легковесный микрофреймворк, идеально подходит для REST API, гибкая настройка маршрутизации

MySQL	Надежная реляционная СУБД, отлично подходит для интернет-магазинов со сложными связями (товары-заказы-пользователи)

Обоснование: Python обеспечивают быструю разработку API. MySQL гарантирует целостность данных, поддержку транзакций и высокую производительность при работе с большими объемами данных.



3.4. Визуальное проектирование интерфейса

Вариант В: Подробное текстовое описание с разметкой



Страница 1: Главная (/)

Тип доступа: публичный



Основные блоки:



Шапка (Header): логотип "HADUKEN", навигационное меню (Главная, Каталог, О нас), иконка поиска, иконка корзины, кнопка "Войти"/аватар пользователя

Hero-блок: заголовок "Уличная одежда HADUKEN", подзаголовок "Стиль, который говорит сам за себя", кнопка "Смотреть новую коллекцию" (ссылка на каталог)

Секция "Акции": баннеры с текущими скидками (данные из GET /api/promotions?active=true)

Секция "Новые поступления": горизонтальный скролл из 6 карточек товаров (данные из GET /api/items?new=true\&limit=6)

Секция "Популярные товары": сетка 4x2 из 8 карточек товаров (данные из GET /api/items?popular=true\&limit=8)

Секция "Отзывы": слайдер с отзывами покупателей (данные из GET /api/reviews)

Футер (Footer): контакты, ссылки на соцсети, информация о доставке и возврате

Страница 2: Аутентификация (/auth)

Тип доступа: публичный



Состояния:



Вход: форма (email/логин, пароль), кнопка "Войти", ссылка "Забыли пароль?", ссылка "Создать аккаунт"



Регистрация: форма (имя, email, пароль, подтверждение пароля), кнопка "Зарегистрироваться"



Восстановление пароля: форма (email), кнопка "Отправить ссылку для восстановления"



Динамический контент: обработка отправки формы с валидацией на клиенте и отправкой на POST /api/auth/login, POST /api/auth/register, POST /api/auth/forgot-password



Страница 3: Каталог (/catalog)

Тип доступа: публичный



Основные блоки:



Шапка и футер (общие для всех страниц)

Боковая панель фильтров:

Категории: Футболки, Худи/Свитшоты, Штаны, Аксессуары

Размеры: XS, S, M, L, XL, XXL

Цена: ползунок от минимальной до максимальной цены

Сортировка: выпадающий список (по новизне, по цене ↑, по цене ↓, по популярности)

Сетка товаров: карточки товаров (изображение, название, цена, рейтинг)

Пагинация: кнопки "Загрузить еще" или постраничная навигация

Динамический контент: товары загружаются с GET /api/items?category=\&size=\&min\_price=\&max\_price=\&sort=\&page=\&limit=12



Состояние загрузки: скелетоны-карточки



Состояние ошибки: сообщение "Не удалось загрузить товары. Попробуйте позже."



Страница 4: Детальная страница товара (/catalog/<id>)

Тип доступа: публичный



Основные блоки:



Хлебные крошки: Главная / Каталог / Категория / Название товара

Галерея изображений: главное фото + миниатюры

Блок информации:

Название товара

Цена (с возможной скидкой)

Рейтинг и количество отзывов

Выбор размера (кнопки XS-XXL, отображать наличие)

Количество товара (счетчик)

Кнопки: "В корзину", "В избранное"

Табы:

Описание: состав, характеристики

Таблица размеров (сравнение размеров)

Доставка и возврат

Отзывы: список отзывов с возможностью оставить отзыв для авторизованных

Динамический контент: данные из GET /api/items/<id>, отзывы из GET /api/items/<id>/reviews



Страница 5: Личный кабинет (/profile)

Тип доступа: приватный (требуется авторизация)



Основные блоки:



Боковое меню: Личные данные, Мои заказы, Избранное, Выход

Блок личных данных:

Аватар (иконка пользователя)

Форма: Имя, Email, Телефон, Адрес доставки

Кнопка "Сохранить изменения"

Динамический контент: данные загружаются с GET /api/user/profile, сохраняются через PUT /api/user/profile



Страница 6: История заказов (/profile/orders)

Тип доступа: приватный



Основные блоки:



Список заказов (аккордеон или карточки):

Номер заказа

Дата

Сумма

Статус (Ожидает оплаты, В обработке, В пути, Доставлен)

Кнопка "Подробнее" для раскрытия деталей

Детали заказа:

Список товаров с количеством и ценой

Итоговая сумма

Адрес доставки

Динамический контент: GET /api/user/orders



Страница 7: Избранное (/profile/favorites)

Тип доступа: приватный



Основные блоки:



Сетка товаров (аналогично каталогу) с возможностью удаления из избранного

Кнопка "Добавить все в корзину"

Пустое состояние: сообщение "В избранном пока ничего нет" и ссылка на каталог

Динамический контент: GET /api/user/favorites, DELETE /api/user/favorites/<item\_id>



Страница 8: Корзина (/cart)

Тип доступа: приватный



Основные блоки:



Таблица товаров:

Изображение, название, размер, цена, количество (счетчик), итого за позицию

Кнопка удаления

Блок итогов:

Промокод (поле ввода и кнопка "Применить")

Сумма за товары

Доставка (бесплатно от 5000 руб.)

Итоговая сумма

Кнопка "Оформить заказ"

Пустое состояние: сообщение "Корзина пуста" и ссылка на каталог

Динамический контент: GET /api/cart, POST /api/cart, PUT /api/cart/<id>, DELETE /api/cart/<id>



Страница 9: Поиск (/search?q=)

Тип доступа: публичный



Основные блоки:



Строка поиска с сохраненным запросом

Результаты поиска: сетка карточек товаров

Состояния:

Поиск: спиннер

Результаты найдены: отображение карточек

Результатов нет: сообщение "По запросу '\[запрос]' ничего не найдено"

Динамический контент: GET /api/search?q={query}



Страница 10: Админ-панель (/admin)

Тип доступа: приватный (только администраторы)



Основные блоки:



Дашборд: статистика (количество заказов, выручка, количество пользователей)

Управление товарами: таблица товаров с возможностью добавления/редактирования/удаления

Управление заказами: список всех заказов с возможностью изменения статуса

Управление пользователями: список пользователей, возможность блокировки/выдачи прав админа

Динамический контент: GET /api/admin/\*, POST /api/admin/\*, PUT /api/admin/\*, DELETE /api/admin/\*
